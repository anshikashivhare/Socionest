# SocioNest Web

Responsive React + Vite web application for Resident, Worker, Security and Admin roles.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally
```bash
npm install
npm run dev
```

Open the URL shown by Vite, usually http://localhost:5173.

## Production build
```bash
npm run build
npm run preview
```

This first milestone is mock-data-first. Backend and authentication are intentionally not required.
